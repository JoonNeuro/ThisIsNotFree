# Brand identity

`ZeroBanknote-v1.png` is the approved current app artwork: a completely fictional distinguished figure on a zero-value banknote, rendered with fine forest-green intaglio hatching on ivory. Generated with the built-in image generation tool. [Approved artwork prompt](ZeroBanknote-v1-prompt.txt). `Scripts/make-icon.swift` packages this unchanged artwork into the app ICNS.

## Earlier explorations

`MouthArtwork-v3.png` is a previous exploration: an exaggerated lower face with inflated cheeks, philtrum, chin, and forceful F articulation. Created with the built-in image generation tool. [Current revision prompt](MouthArtwork-v3-prompt.txt).

`MouthArtwork-v2.png` is the earlier mouth-only cartoon artwork, generated by editing the first concept with the built-in image generation tool. It exaggerates the forceful F articulation and replaces red lipstick with muted taupe. [Revision prompt](MouthArtwork-v2-prompt.txt).

`MouthArtwork-v1.png` was generated with the built-in image generation tool for this project. It is retained as the original painted concept; these earlier mouth concepts are retained for reference. `Scripts/make-icon.swift` packages it into icon sizes and ICNS. The original box icon remains recoverable in Git history.

The menu bar uses the independently drawn, transparent, monochrome 20 × 20 point zero coin in `Sources/MacAudioMixer/BrandIcon.swift`. macOS supplies light/dark template rendering. Settings also offers a dollar coin and custom image imports.

## Generation prompt

Use case: logo-brand. Create one polished square macOS app icon concept for a utility app named This Is Not Free, inspired by the witty surreal juxtaposition of a plainly painted object and its contradictory name. Subject: a large isolated human mouth at the very beginning of saying the English word FREE: an unmistakable F articulation, upper front teeth gently touching the inner lower lip, with a small dark slit behind. Mouth only, no face, nose, chin, hands, coins or other objects. Frontal view. Matte muted vermilion red lips, simplified ivory upper teeth, deep warm charcoal mouth interior. Restrained elegant surrealist oil-paint illustration with very subtle brushwork and broad sculptural shapes, clean edges, no skin pores or hyperreal dental detail. Warm flat ivory background fills the square edge to edge. The wide mouth occupies about 78 percent of the width, centered, a little above the vertical midpoint. Sophisticated, slightly absurd, neutral expression, not smiling, not sensual, not glossy. Strong recognizable silhouette which can later be adapted into a mouth-only monochrome menu-bar mark. No writing, lettering, captions, watermark, border, drop shadow, device mockup or pre-rounded icon container. Output a single standalone square icon artwork.
